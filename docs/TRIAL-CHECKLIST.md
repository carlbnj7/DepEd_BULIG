# BULIG classroom trial (2 weeks)

A short trial with real teachers and pupils finds problems no code check can find: words children do not
understand, buttons that are hard to tap, steps teachers skip. Run it before rolling BULIG out widely.

## Who

- **2 teachers** from different grades (one Grade 1–2, one Grade 4–6).
- **8 to 10 pupils** per teacher, mixed reading levels. Include at least two who start above Level 1.
- **1 person who watches and writes notes** (you). Do not help unless a child is stuck for more than a minute;
  write down where they got stuck.

## Before the trial (admin)

- [ ] System health shows every check OK, and a backup was made today.
- [ ] Create the two teacher accounts and print their Teacher Passes.
- [ ] Each teacher adds a section and imports or adds their pupils, then prints Reading Passes.
- [ ] Try one pupil account on a phone, a tablet and a school computer.

## What to watch

**Week 1, with the teacher in the room**

| Pupils | Teachers |
|---|---|
| Sign in with the Reading Pass (scan) and with ID and password. | Set starting levels for each pupil. |
| Finish one lesson: listen, speak, tap, draw. | Run one Class Demo on the projector. |
| Use "I need help" once. | Check answers in Review, send one "Try again". |
| See their XP, reader level and badges. | Print one progress report. |

**Week 2, at home or in free time**

| Pupils | Teachers |
|---|---|
| Use BULIG without help for 3 days. | Check the dashboard: who needs a check-in? |
| Download lessons and try one offline. | Answer every help request within a day. |

## Write down

For each problem: **who** (pupil, teacher), **which page**, **what they tried**, **what happened**, and a photo
of the screen if you can. Note the phone or computer used.

Also count: how many minutes a lesson takes, how many pupils signed in without help, and how many help taps
were used.

## Questions at the end

**Pupils** (ask out loud, let them point at the screen)
1. What did you like most?
2. Was anything hard to do? Show me.
3. Did you understand what to do on every page?

**Teachers**
1. Which page did you use most? Which did you never open?
2. What took longer than it should?
3. Did anything give a wrong result (XP, levels, scores, reports)?
4. What would stop other teachers from using BULIG?

Bring the notes back, and we will fix the top problems before the full rollout.
