"Done in class": teacher marks progress

When you teach a level with Class Demo, you can mark it as done for the pupils who were there. Their next lesson or level opens right away.

AFrom Class Demo: mark the whole class at once

A new gold Mark as done button sits in the Class Demo top bar. When you finish teaching, tap it, choose how much you covered, and untick any pupil who was absent.

BFrom a pupil's progress page: one pupil at a time

On My pupils → (pupil name), a new Learning path card lists every level and lesson. Tick the lessons that were done in class, or mark a whole level in one tap. Good for a pupil who joined late, or for catching up one child.
