Animation ideas for BULIG

The pupil dashboard, sign-in page, celebrations and the learning map already have lots of motion. These 8 ideas add movement where there is none yet: moving between pages, inside activities, the microphone, feedback and the admin numbers. Each frame below is a moment in the animation, left to right.

1Smooth page changesRecommendedEveryone

Now every page change is a sudden jump. Instead, the old content fades out and the new content slides in gently, while the menu and header stay still. Built into modern browsers, so it costs almost nothing.
