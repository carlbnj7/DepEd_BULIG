BULIG - George's new friends: drawing prompts for ChatGPT
=========================================================

HOW TO USE
1. Start a new ChatGPT chat and upload one George picture (for example george-hello.webp) so it can copy her style.
2. Paste the STYLE text below, then the text for ONE character.
3. Ask for ONE pose per image. Do the 5 poses one by one, in the same chat, so the character stays the same.
4. Save each image as .webp (or .png) with the file name shown, and send them back in one ZIP.

STYLE (paste this every time)
-----------------------------
Same art style as the attached George the Explorer picture: cute cartoon chibi style for young
Filipino pupils (Grades 1-6), big head and big shiny eyes, friendly open smile, thick dark brown
outlines, soft shading, bright warm colours. Full body from head to shoes, standing, facing the viewer.
Transparent background, no shadow on the ground, no text, no logo, no frame.
Tall portrait image (about 3 wide x 4 tall). Leave a little empty space around the character.
Keep the character exactly the same in every pose (face, hair, clothes, colours).

THE 5 POSES (same for every character)
--------------------------------------
  -hello   waving with one hand, happy smile
  -point   pointing to the side with one hand, one foot stepping forward
  -thumbs  thumbs-up with one hand, winking
  -cheer   jumping with joy, one arm up
  -special the character's own pose (written under each character)

--------------------------

around his neck. Light blue T-shirt with a small sound-wave print, navy shorts, white sneakers
